# 🏓 Ping Pong на Pygame

Простая реализация классической игры **Пинг-Понг**, написанная на Python с использованием библиотеки Pygame.

## Возможности

- Управление двумя ракетками с клавиатуры.
- Случайное направление полёта мяча при старте игры.
- Отскок мяча от верхней и нижней границ поля.
- Отскок мяча от ракеток игроков.
- Определение победителя при пропуске мяча.
- Ограничение FPS для стабильной работы игры.

## Управление

### Левый игрок
- W — вверх
- S — вниз

### Правый игрок
- ↑ — вверх
- ↓ — вниз

## Используемые классы

### GameSprite
Базовый класс для всех игровых объектов.

### Platform
Класс ракетки игрока.

### Ball
Класс мяча со случайным направлением движения.

## Игровая логика

1. Создаются две ракетки.
2. Создаётся мяч.
3. Игровой цикл обновляет объекты 60 раз в секунду.
4. При столкновении с ракеткой мяч меняет направление.
5. При выходе за границы определяется победитель.
